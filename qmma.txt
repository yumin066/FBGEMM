Description
WARNING: QMMA is EXPERIMENTAL_EXTERNAL.

Note: QMMA is a Warp Cooperative Operation.

QMMA performs a MxNxK matrix multiply and accumulate across the entire warp. It performs D = A*B+C, where the A matrix is MxK, the B matrix is KxN, and the C and D matrices are MxN. Threads within the same quad collectively contribute a row and a column of the input matrices A and B, respectively, and are mapped to a unique row of accumulator elements.

Source formats for matrices A and B are controlled separately. QMMA.16816 and QMMA.SP.16832 support formats E5M2 and E4M3. QMMA.16832 and QMMA.SP.16864 support formats E5M2, E4M3, E3M4, E3M2, E2M3, and E2M1.

4-bit (E2M1) and 6-bit (E3M2, E2M3) elements must be packed in 8-bit containers. For 6-bit formats, the element is read from the lower 6 bits of the container (padding in the upper 2 bits of the container). For 4-bit formats, the element is read from the central 4 bits of the container (padding in the upper 2 bits and lower 2 bits of the container).

The format for matrices C and D can be F16 or F32. When .SF is specified, it must be F32.

The A, C, and D matrices are row-major whereas the B matrix is column-major. This instruction is a warp wide operation. If the threads in the warp are not predicated either all on or all off, results are UNPREDICTABLE.

The uniform predicate UPp controls whether the C operand is read. If UPp is unspecified, then it is assembled as UPT by default. The C operand is read when UPp is True, and it is ignored when UPp is False.

Block Scaling Factors
When .SF is specified, block scaling factors are applied to the source A and B matrices. It performs D = A*SF_A * B*SF_B + C, where SF_A is the scaling factors for A in the form Mx1 and SF_B is the scaling factors for B in the form Nx1.

With .SF, the only allowed size is .16832 (non-.SP) or .SP.16864.

The scaling factors always use the E8 format.

ScaleID_A selects SF_A from the scale A metadata provided in Re if .SP is not specified, or Re+1 if .SP is specified (in which case, Re must be 64b-aligned). ScaleID_B selects SF_B from the scale B metadata provided in Rh. ScaleID_A and ScaleID_B are each composed of a Byte ID and Thread ID component. They are provided in URi as shown below.

  31            7 6             5 4             3 2             2 1             0
 +--------------------------------------URi--------------------------------------+ 
 +---------------+---------------+---------------+---------------+---------------+
 |    Reserved   |  ThreadID_B   |   ByteID_B    |  ThreadID_A   |   ByteID_A    |
 +---------------+---------------+---------------+---------------+---------------+
ByteID_A is a 2-bit field indicating which byte of Re (or Re+1 for sparse) is selected for SF_A, with ByteID_A=0 indicating the lowest byte, ByteID_A=1 indicating the next lowest byte, etc.

ThreadID_A=0 indicates that SF_A is selected from thread IDs tid such that tid % 4 == 0 and tid % 4 == 1 (i.e. the lower two threads of each quad), and ThreadID_A=1 indicates that SF_A is selected from thread IDs tid such that tid % 4 == 2 and tid % 4 == 3 (i.e. the upper two threads of each quad).



ByteID_B is a 2-bit field indicating which byte of Rh is selected for SF_B, with ByteID_B=0 indicating the lowest byte, ByteID_B=1 indicating the next lowest byte, etc.

ThreadID_B is a 2-bit field indicating that SF_B is selected from thread IDs tid such that tid % 4 == ThreadID_B (i.e. one thread per quad provides metadata for SF_B).



Note: If Rh.reuse is specified and the following MMA instruction that reads the value from the same register has a different ThreadID_B, then .reuse is ignored and the later instruction reads Rh from the register file.

Sparsity
For the sparse variants, matrix A is structured sparse with 50% zeroes and Matrices B, C and D are dense. For an MxNxK sparse variant, matrix A is still MxK, but Ra packs only MxK/2 elements. For each K-wide row of matrix A, K/2 elements are zeroes and only the remaining K/2 elements are packed in the corresponding quad of Ra. Data from each quad in Re provides the meta data which describes how the K/2 elements in each row are mapped to the K-wide row of matrix A.

Matrix A is structured sparse at a granularity of 2:4. In other words, each chunk of four adjacent elements in a row of matrix A have two zeroes and two non-zero elements. Only the two non-zero elements are stored in Ra and two 2-bit indices in the meta data register Re indicate the position of these two non-zero elements in the four-wide chunk. Refer to the Additional Information section for more on register packing.



For the sparse variants, all of Re may not required to encode the meta data. The 2-bit immediate #sparseId, together with the .spformat modifier determines how the meta data is sourced from Re.

For QMMA.SP.16832, a thread-pair within the quad or a byte-pair within Re contributes the metadata. Hence, #sparseId must be 0 or 1. A value of #sparseId greater than 1 produces an ILLEGAL_INSTR_ENCODING error.
When .spformat is .TID, one thread-pair within the quad, determined by #sparseId, contributes the meta data for the entire quad.
When .spformat is .REGOFFSET, one byte-pair (16 bits or half word) within Re, determined by #sparseId, contributes the metadata for the thread.
For QMMA.SP.16864, all threads within the quad or all bytes within Re(+0) contribute the metadata. Hence, #sparseId must be 0. A value of #sparseId greater than 0 produces an ILLEGAL_INSTR_ENCODING error.
Refer to the additional information section for more on this.

If a pair of 2-bit indices packed in Re(+0) with 4-bit alignment are the same, then the result is UNPREDICTABLE. Specifically, the following nibble-aligned nibbles should be avoided from being packed into Re(+0):

0x0
0x5
0xA
0xF
Additionally, due to implementation nuances, packing Re(+0) with the following nibble-aligned nibbles also has UNPREDICTABLE results:

0x1
0x2
0x3
0x7
0xB

fp32 UINT_TO_FP32(uint32_t in, FPFMT inFmt) {
    fp32 out;
    switch(inFmt) {
        case F16:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\fp16>(in & 0x0000ffff)), F16, F32, RN);
            break;
        case F32:
            out = reinterpret_cast<\fp32>(in);
            break;
        case E5M2:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e5m2>(in & 0x000000ff)), E5M2, F32, RN);
            break;
        case E4M3:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e4m3>(in & 0x000000ff)), E4M3, F32, RN);
            break;
        case E3M4:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e3m4>(in & 0x000000ff)), E3M4, F32, RN);
            break;
        case E3M2:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e3m2>(in & 0x000000ff)), E3M2, F32, RN);
            break;
        case E2M3:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e2m3>(in & 0x000000ff)), E2M3, F32, RN);
            break;
        case E2M1:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e2m1>(in & 0x000000ff)), E2M1, F32, RN);
            break;
        case E8:
            //Rounding mode does not matter for up converts
            out = fpConvert((reinterpret_cast<\e8>(in & 0x000000ff)), E8, F32, RN);
            break;
        default:
            ARCH_ASSERTION(0);
    }
    return out;
}

    sfb_thread_id  =  (URiValue >> 5) & 0x3;
}

// ----------- STEP 1: Populate matrixE from Re and scale MD from Re/Rh ----------
parallel_foreach_active_thread {
    // If not all threads are active and either predicated all on or all off,
    // then results are UNPREDICTABLE
    if (guardPredicateTestFails()) {
        UNPREDICTABLE;
    }

    int quad_number    = [Thread]laneId >> 2;
    int thread_in_quad = [Thread]laneId & 0x3;

    if(sparse && (inst.spformat == .TID)) {
        // Each thread contributes
        // E__TID__ELEMENTS_PER_THREAD_PER_TILE * E__TID__NUM_TILES_X * E__TID__NUM_TILES_Y
        // elements to the E matrix, spread across multiple rows and columns.
        // The diagrams in the additional information section illustrate which
        // threads provide which matrix elements.
        e_data_type RVal_E[E__TID__ELEMENTS_PER_THREAD_PER_TILE * E__TID__NUM_TILES_X * E__TID__NUM_TILES_Y];
        if( ((1 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) && (thread_in_quad == inst.#id2))     ||
            ((2 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) && ((thread_in_quad == (2*inst.#id2)) || (thread_in_quad == ((2*inst.#id2)+1)))) ||
            (4 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA)
          ) {
            int thread_row_index;
            int thread_col_index;
            if(1 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) {
                thread_row_index = 0;
                thread_col_index = 0;
            } else if(2 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) {
                thread_row_index = (thread_in_quad == ((2*inst.#id2)+1)) ? 1 : 0;
                thread_col_index = 0;
            } else if(4 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) {
                thread_row_index = thread_in_quad % 2;
                thread_col_index = thread_in_quad / 2;
            }
            if((2 == E__TID__NUM_THREADS_IN_QUAD_PROVIDING_META_DATA) && (thread_in_quad == ((2*inst.#id2)+1))) {
                thread_index_within_meta_data_providing_threads = 1;
            } else {
                thread_index_within_meta_data_providing_threads = 0;
            }
            REG_READ((uint32_t*)RVal_E, inst.Re, E__TID__REGISTER_SIZE);
            int reg_index_e = 0;
            for(int c=0; c<E__TID__NUM_TILES_Y; c++) {
                for(int r=0; r<E__TID__NUM_TILES_X; r++) {
                    for(int i=0; i<E__TID__ELEMENTS_PER_THREAD_PER_TILE; i++) {
                        int row = (r * E__TID__TILE_SIZE_X) + (thread_row_index * E__TID__TILE_SIZE_X) + quad_number;
                        int col = (c * E__TID__TILE_SIZE_Y) + (thread_col_index * E__TID__ELEMENTS_PER_THREAD_PER_TILE) + i;
                        matrixE[row][col] = RVal_E[reg_index_e++];
                    }
                }
            }
        }
    }
    if(sparse && (inst.spformat == .REGOFFSET)) {
        // Each thread contributes
        // E__REGOFFSET__ELEMENTS_PER_THREAD_PER_TILE * E__REGOFFSET__NUM_TILES_X * E__REGOFFSET__NUM_TILES_Y
        // elements to the E matrix, spread across multiple rows and columns.
        // The diagrams in the additional information section illustrate which
        // threads provide which matrix elements.
        e_data_type RVal_E[E__REGOFFSET__ELEMENTS_PER_THREAD_PER_TILE * E__REGOFFSET__NUM_TILES_X * E__REGOFFSET__NUM_TILES_Y];
        REG_READ((uint32_t*)RVal_E, inst.Re, E__REGOFFSET__REGISTER_SIZE);
        int reg_index_e = 0;
        for(int c=0; c<E__REGOFFSET__NUM_TILES_Y; c++) {
            for(int r=0; r<E__REGOFFSET__NUM_TILES_X; r++) {
                for(int i=0; i<E__REGOFFSET__ELEMENTS_PER_THREAD_PER_TILE; i++) {
                    int row = (r * E__REGOFFSET__TILE_SIZE_X) + quad_number;
                    int col = (c * E__REGOFFSET__TILE_SIZE_Y) + (thread_in_quad * E__REGOFFSET__ELEMENTS_PER_THREAD_PER_TILE) + i;
                    matrixE[row][col] = RVal_E[(E__REGOFFSET__NUM_ELEMENTS_PER_THREAD * inst.#id2) + (reg_index_e++)];
                }
            }
        }
    }
    if (scale) {
        // Each thread contributes 32bits of possible MD from Re (+1 if sparse) and Rh
        uint32_t RVal_E;
        uint32_t RVal_H;
        if (sparse) {
            REG_READ((uint32_t*)RVal_E, inst.Re + 1, 32);
        } else {
            REG_READ((uint32_t*)RVal_E, inst.Re, 32);
        }
        REG_READ((uint32_t*)RVal_H, inst.Rh, 32);
        if (((sfa_thread_id*16 + 16) > [Thread]laneId) && (sfa_thread_id*16 <= [Thread]laneId))
            matrixSFA[quad_number + thread_in_quad * 8] = (RVal_E >> (sfa_id_byte_id * 8)) & 0xFF;
        if (((sfb_thread_id*8 + 8) > [Thread]laneId) && (sfb_thread_id*8 <= [Thread]laneId))
            matrixSFB[quad_number + thread_in_quad * 8] = (RVal_H >> (sfa_id_byte_id * 8)) & 0xFF;
    }

}

// ----------- STEP 2: Read Ra, Rb & Rc ----------
parallel_foreach_active_thread {
    int quad_number    = [Thread]laneId >> 2;
    int thread_in_quad = [Thread]laneId & 0x3;

    // ----------- STEP 2.1: populate matrixA from Ra  ----------
    // Each thread contributes
    // A_ELEMENTS_PER_THREAD_PER_TILE * A_NUM_TILE_X * A_NUM_TILE_Y
    // elements to the A matrix, spread across multiple rows and columns.
    // The diagrams in the additional information section illustrate which
    // threads provide which matrix elements.
    a_data_type RVal_A[A_ELEMENTS_PER_THREAD_PER_TILE * A_NUM_TILES_X * A_NUM_TILES_Y];
    REG_READ((uint32_t*)RVal_A, inst.Ra, A_REGISTER_SIZE);
    int reg_index_a = 0;
    for(int c=0; c<A_NUM_TILES_Y; c++) {
        for(int r=0; r<A_NUM_TILES_X; r++) {
            for(int i=0; i<A_ELEMENTS_PER_THREAD_PER_TILE; i++) {
                int row = (r * A_TILE_SIZE_X) + quad_number;
                int col = (c * A_TILE_SIZE_Y) + (thread_in_quad * A_ELEMENTS_PER_THREAD_PER_TILE) + i;
                if(sparse) {
                    int offset = matrixE[row][col/METADATA_FOOTPRINT];
                    // If a pair of metadata in a nibble is equal, the result is UNPREDICTABLE;
                    if (((col/METADATA_FOOTPRINT) % 2 == 0) && (matrixE[row][1 + (col/METADATA_FOOTPRINT)] == offset)) {
                        UNPREDICTABLE;
                    }
                    col = ((col / SPARSE_RATIO) * 4) + offset; //2:4 sparsity
                }
                matrixA[row][col] = UINT_TO_FP32((uint32_t)(RVal_A[reg_index_a++]), inst.srcFmtA);
            }
        }
    }

    // ----------- STEP 2.2: populate matrixB from Rb  ----------
    // Each thread contributes
    // B_ELEMENTS_PER_THREAD_PER_TILE * B_NUM_TILE_X * B_NUM_TILE_Y
    // elements to the B matrix, spread across multiple rows and columns.
    // The diagrams in the additional information section illustrate which
    // threads provide which matrix elements.
    b_data_type RVal_B[B_ELEMENTS_PER_THREAD_PER_TILE * B_NUM_TILES_X * B_NUM_TILES_Y];
    REG_READ((uint32_t*)RVal_B, inst.Rb, B_REGISTER_SIZE);
    int reg_index_b = 0;
    for(int c=0; c<B_NUM_TILES_Y; c++) {
        for(int r=0; r<B_NUM_TILES_X; r++) {
            for(int i=0; i<B_ELEMENTS_PER_THREAD_PER_TILE; i++) {
                int row = (r * B_TILE_SIZE_X) + (thread_in_quad * B_ELEMENTS_PER_THREAD_PER_TILE) + i;
                int col = (c * B_TILE_SIZE_Y) + quad_number;
                matrixB[row][col] = UINT_TO_FP32((uint32_t)(RVal_B[reg_index_b++]), inst.srcFmtB);
            }
        }
    }

    // ----------- STEP 2.3: populate matrixC from Rc  ----------
    // Each thread contributes
    // C_ELEMENTS_PER_THREAD_PER_TILE * C_NUM_TILE_X * C_NUM_TILE_Y
    // elements to the C matrix, spread across multiple rows and columns.
    // The diagrams in the additional information section illustrate which
    // threads provide which matrix elements.
    c_data_type RVal_C[C_ELEMENTS_PER_THREAD_PER_TILE * C_NUM_TILES_X * C_NUM_TILES_Y];
    REG_READ((uint32_t*)RVal_C, CIndex, C_REGISTER_SIZE);
    int reg_index_c = 0;
    for(int c=0; c<C_NUM_TILES_Y; c++) {
        for(int r=0; r<C_NUM_TILES_X; r++) {
            for(int i=0; i<C_ELEMENTS_PER_THREAD_PER_TILE; i++) {
                int row = (r * C_TILE_SIZE_X) + quad_number;
                int col = (c * C_TILE_SIZE_Y) + (thread_in_quad * C_ELEMENTS_PER_THREAD_PER_TILE) + i;
                matrixC[row][col] = UINT_TO_FP32(RVal_C[reg_index_c++], inst.dstfmt);
            }
        }
    }
}

// ----------- STEP 3: Perform matrix-multiply-accumulate ----------
for (int m=0; m<M_DIM; m++) {
    for (int n=0; n<N_DIM; n++) {
        for (int k=0; k<K_DIM; k++) {

            // NaN generation
            if(fpIsInf(matrixC[r][c], dstfmt) && (fpIsInf(matrixA[r][k], inst.srcFmtA) || fpIsInf(matrixB[k][c], inst.srcFmtB))) {
                bool a_sign = fpSign(matrixA[r][k], inst.srcFmtA)
                bool b_sign = fpSign(matrixB[k][c], inst.srcFmtB)
                if (fpSign(matrixC[r][c], INTERNAL_FMT) != a_sign ^ b_sign) {
                    matrixC[r][c] = fpNaN(INTERNAL_FMT);
                }
            }
            // NaN propagation
            if(fpIsNaN(matrixA[r][k], inst.srcFmtA) || fpIsNaN(matrixB[k][c], inst.srcFmtB) || fpIsNaN(matrixC[r][c], dstfmt)) {
                matrixC[r][c] = fpNaN(INTERNAL_FMT);
            }
            // Dot-product computation is approximate
            // Order of accumulation is NOT defined.
            if (scale)
                matrixC[r][c] += (matrixA[r][k] * UINT_TO_FP32(matrixSFA[r], E8)) * (matrixB[k][c] * UINT_TO_FP32(matrixSFB[c], E8));
            else
                matrixC[r][c] += matrixA[r][k] * matrixB[k][c];
        }
        // Rounding mode does not matter because the operation is approximate
        matrixD[r][c] = fpConvert(matrixC[r][c], INTERNAL_FMT, dstfmt, RN);
        if (fpIsZero(matrixD[r][c], dstfmt)) {     // Either +0.0 or -0.0
            matrixD[r][c] = 0;                          // Force +0.0
        }
    }
}

// ----------- STEP 4: Pack the results into Rd ----------
parallel_foreach_active_thread {
    int quad_number    = [Thread]laneId >> 2;
    int thread_in_quad = [Thread]laneId & 0x3;

    // Each thread packs
    // D_ELEMENTS_PER_THREAD_PER_TILE * D_NUM_TILE_X * D_NUM_TILE_Y
    // elements from the D matrix, spread across multiple rows and columns.
    // The diagrams in the additional information section illustrate which
    // threads pack which matrix elements.
    d_data_type RVal_D[D_ELEMENTS_PER_THREAD_PER_TILE * D_NUM_TILES_X * D_NUM_TILES_Y];
    int reg_index_d = 0;
    for(int c=0; c<D_NUM_TILES_Y; c++) {
        for(int r=0; r<D_NUM_TILES_X; r++) {
            for(int i=0; i<D_ELEMENTS_PER_THREAD_PER_TILE; i++) {
                int row = (r * D_TILE_SIZE_X) + quad_number;
                int col = (c * D_TILE_SIZE_Y) + (thread_in_quad * D_ELEMENTS_PER_THREAD_PER_TILE) + i;
                RVal_D[reg_index_d++] = reinterpret_cast<d_data_type>(matrixD[row][col]);
            }
        }
    }
    REG_WRITE((uint32_t*)RVal_D, inst.Rd, D_REGISTER_SIZE);
}

updatePcToNextInstruction();
