Guard Predicate
.sz:
{.16, .U4TO8, .S4TO8, .U2TO4, .S2TO4, .U4x16P64TO8, .U6x16P32TO8, .8}
.16 - unsigned 16-bit elements. Mode is .M88 or .MT88.
.U4TO8 - unsigned 4-bit data stored in Rd zero-exteneded to 8 bits. Mode is M816.
.S4TO8 - signed 4-bit data stored in Rd sign-exteneded to 8 bits. Mode is M816.
.U2TO4 - unsigned 2-bit data stored in Rd zero-extended to 4 bits. Mode is M832.
.S2TO4 - signed 2-bit data stored in Rd sign-exteneded to 4 bit. Mode is M832.
.U4x16P64TO8 - SMEM source is a 16B chunk containing 16 U4 elements followed by a padding of 64 bits. Destination is unsigned 8 bit container. Mode is M816 or MT1616.
.U6x16P32TO8 - SMEM source is a 16B chunk containing 16 U6 elements followed by a padding of 32 bits. Destination is unsigned 8 bit container. Mode is M816 or MT1616.
.8 - unsigned 8-bit elements. Mode is MT1616.
.mode:
{.M88, .MT88, .M816, .M832, .MT1616}
.M88 - Perform an 8x8 matrix load - row-major
.MT88 - Perform an 8x8 matrix load with transposition - column-major
.M816 - Perform an 8x16 matrix load - row-major
.M832 - Perform an 8x32 matrix load - row-major
.MT1616 - Perform a 16x16 matrix load with transposition - column-major (only valid with .num={.1, .2})
.num:
{.1*, .2, .4}
The number of matrices to load
Rd:
Destination register
Ra:
Source A register, representing an address or offset
#immS24:
Signed 24-bit integer value.
URb:
Source B uniform register representing an address or offset

{.(null)*, .8.M816, .4.M832, .2.M864, .1.M8128}
Non-functional tag indicating different element size/matrix dimension combinations that also map to an 8x8 matrix of 16-bit elements.

Description
WARNING: .sz={.U4TO8, .S4TO8, .U2TO4, .S2TO4, .U4x16P64TO8, .U6x16P32TO8} is EXPERIMENTAL_EXTERNAL.

Note: LDSM is a Warp Cooperative Operation.

Load from shared memory one, two, or four matrices into a warp-wide register. All threads must be active and predicated either all on or all off, otherwise the results are UNPREDICTABLE. The matrices are loaded according to one of the following modes:

8x8 matrices of 16-bit elements with optional transposition: .16.M88 or .16.MT88
8x16 matrices of unsigned 4-bit elements in shared memory expanded to 8-bit elements in Rd: .U4TO8.M816
8x16 matrices of signed 4-bit elements in shared memory expanded to 8-bit elements in Rd: .S4TO8.M816
8x16 matrices of unsigned 4-bit elements in shared memory, with 8B of padding per 16B, expanded to 8-bit elements in Rd: .U4x16P64TO8.M816
8x16 matrices of unsigned 6-bit elements in shared memory, with 4B of padding per 16B, expanded to 8-bit elements in Rd: .U6x16P32TO8.M816
8x32 matrices of unsigned 2-bit elements in shared memory expanded to 4-bit elements in Rd: .U2TO4.M832
8x32 matrices of signed 2-bit elements in shared memory expanded to 4-bit elements in Rd: .S2TO4.M832
16x16 matrices of unsigned 4-bit elements in shared memory, with 8B of padding per 16B, expanded to 8-bit elements in Rd with transposition: .U4x16P64TO8.MT1616
16x16 matrices of unsigned 6-bit elements in shared memory, with 4B of padding per 16B, expanded to 8-bit elements in Rd with transposition: .U6x16P32TO8.MT1616
16x16 matrices of 8-bit elements with transposition: .8.MT1616
For modes .M88, .MT88, .M816, and .M832, Rd is 32b-wide when .num=1, Rd is 64b-wide when .num=2, and Rd is 128b-wide when .num=4.

For mode .MT1616, Rd is 64b-wide when .num=1, and Rd is 128b-wide when .num=2. .MT1616 doesn't allow .num=4.

The loaded elements are packed in 32-bit registers across the warp. Row-major packing is the default; loading with transposition implies column-major packing and is only allowed when loading 8x8 or 16x16 matrices.

Except for with mode .MT1616, the addresses that point to each nth matrix come from the nth set of eight threads in the warp: the first matrix loaded uses the eight addresses in the first eight threads, which point to a contiguous 16B region in memory, the second matrix loaded uses the eight addresses from the second set of eight threads in the warp, and so on. With mode .MT1616, the addresses that point to each nth matrix come from the nth set of sixteen threads in the warp: the first matrix loaded uses the sixteen addresses in the first sixteen threads, and the second matrix loaded uses the sixteen addresses in the second sixteen threads.

With .*.MT1616, 256 bits are loaded from shared memory per quad per matrix.

With .*.M88, .*.MT88, .U4x16P64TO8.M816, and .U6x16P32TO8.M816, 128 bits are loaded from shared memory per quad per matrix.

With .*.M832, .U4TO8.M816, and .S4TO8.M816, 64 bits are loaded from shared memory per quad per matrix.

When the CTA to which the current warp belongs, is part of a CGA, the shared memory address can only be a local DSMEM address.

The destination CTA ID (logical CTA ID in CGA) is specified in bits [31:24]. This value should match the local CTA ID, else an ILLEGAL_INSTR_PARAM error is reported.

If the CTA is not a part of a GPC CGA this value is 0, else an ILLEGAL_INSTR_PARAM error is reported.

Bits [23:0] holds the SMEM offset value of the address. This value must be within the 16 MB shared memory window.

The destination register Rd is packed as follows:

Rd Packing for Multiple Matrices (M88, MT88, M816, M832)
# of matrices	Rd Size	Matrix Distribution
1	32-bit	Rd[31:0] - matrix 1
2	64-bit	Rd[31:0] - matrix 1
Rd[63:32] - matrix 2
4	128-bit	Rd[31:0] - matrix 1
Rd[63:32] - matrix 2
Rd[95:64] - matrix 3
Rd[127:96] - matrix 4

Rd Packing for Multiple Matrices (MT1616)
# of matrices	Rd Size	Matrix Distribution
1	64-bit	Rd[63:0] - matrix 1
2	128-bit	Rd[63:0] - matrix 1
Rd[127:64] - matrix 2

Rd Packing per Matrix Dimensions
Matrix Dimensions	Element Size	# Elements in Rd	Expansion
8x8	16	2	None
8x16	8	4	4b-to-8b, 6b-to-8b
8x32	4	8	2b-to-4b
16x16	8	4	None, 4b-to-8b, 6b-to-8b

if (([Warp]shader != CS)) {
    ERROR(ILLEGAL_INSTR_ENCODING);
    updatePcToNextInstruction();

uint8_t num = inst.mode == .MT1616 ? 2*inst.num : inst.num;

const bool URF_used = get_is_uniform_variant_from_abc_urf();

DEST_CHECK(inst.Rd, (32*num)); // Check for MISALIGNED_REG/OOR_REG error

handleInstFieldIllegalInstrEncodings();

uint16_t matrix[4][8][8];

// If not all threads are active then results are UNPREDICTABLE
if ([Warp]ActiveMask != 0xFFFFFFFF) {
    UNPREDICTABLE;
}

//
// Address generation and load data
//
parallel_foreach_active_thread {
    // If not all threads are active and predicated either all on or all off,
    // then results are UNPREDICTABLE
    if (guardPredicateTestFails()) {
        UNPREDICTABLE;
        updatePcToNextInstruction();
        return;
    }

    int quad = [Thread]laneId >> 2;
    int quad_thread = [Thread]laneId & 0x3;

    if ((num ==4) || ((num == 2) && (quad < 4)) || (num == 1) && (quad < 2)) {

        // Register + unsigned or signed offset address
        uint32_t RaValue = 0
        uint32_t URbValue = 0;
        REG_READ(RaValue, inst.Ra, SRC_REG, 32);
        if (URF_used) {
            GET_USOURCE(URbValue, inst.URb, SRC_UREG, 32);
        }
        uint32_t waddr = RaValue + URbValue + sext24(inst.ImmS24);

        // Size and alignment
        uint32_t szBytes;
        switch(inst.mode) {
            case .M88:
            case .MT88:
                szBytes = 16;       // 16 byte access size for 8x8
                break;
            case .M816:
                if (inst.sz == .U4x16P64TO8 || inst.sz == .U6x16P32TO8) {
                    szBytes = 16; 
                }
                else {
                    szBytes = 8; 
                }
                break;
            case .MT1616:
                szBytes = 16;
                break;
            case .M832:
                szBytes = 8;         // 8 bytes loaded for 8x32
                break;
        }
        if ((waddr & (szBytes-1)) != 0) {     // Check address natural alignment
            ERROR(MISALIGNED_ADDR);
            waddr &= ~(szBytes-1);
        }
        
        const uint8_t target_cta_id = (waddr >> 24) & 0xFF;
        const uint32_t shm_ofs = waddr & 0xFF_FFFF;
        uint32_t zero[4] = {0, 0, 0, 0};        
        uint32_t result[4];
        bool shm_error = false;
        if (waddr >= [Global]SMemSz) {      // beyond Shared allocated size
            ERROR(OOR_ADDR);
            result = zero;
            shm_error = true;
        }
        if ([CTA]isGpcCga && target_cta_id > MAX_CTA_ID_IN_CGA) {
            ERROR(ILLEGAL_INSTR_PARAM);
            result = zero;
            shm_error = true;
        }
        if ([CTA]isGpcCga && (target_cta_id != [CTA]LogicalCtaIdInCga)) { // Check for remote access
            ERROR(ILLEGAL_INSTR_PARAM);
            result = zero;
            shm_error = true;
        }
        if (![CTA]isGpcCga && target_cta_id != 0) {  // Check if CTA is part of a CGA
            ERROR(OOR_ADDR);
            result = zero;
            shm_error = true;
        }
        
        if (!shm_error) {
            // map per-CTA Shared mem addr to SRF physical address
            uint32_t caddr = [Global]SMemBase[PhysCTAid] + waddr; 
            SHARED_LOAD(result, caddr, szBytes * 8);
        }

        int row = ((quad & 0x1) << 2) | quad_thread;
        int matrix_num = quad >> 1;
        if (inst.mode == M88 || inst.mode == MT88) { // 128-bit load
            if (inst.mode == M88) {
                // not transposed
                matrix[matrix_num][row][0] = result[0] & 0xFFFF;
                matrix[matrix_num][row][1] = (result[0] >> 16) & 0xFFFF;
                matrix[matrix_num][row][2] = result[1] & 0xFFFF;
                matrix[matrix_num][row][3] = (result[1] >> 16) & 0xFFFF;
                matrix[matrix_num][row][4] = result[2] & 0xFFFF;
                matrix[matrix_num][row][5] = (result[2] >> 16) & 0xFFFF;
                matrix[matrix_num][row][6] = result[3] & 0xFFFF;
                matrix[matrix_num][row][7] = (result[3] >> 16) & 0xFFFF;
            } else {
                // transposed
                matrix[matrix_num][0][row] = result[0] & 0xFFFF;
                matrix[matrix_num][1][row] = (result[0] >> 16) & 0xFFFF;
                matrix[matrix_num][2][row] = result[1] & 0xFFFF;
                matrix[matrix_num][3][row] = (result[1] >> 16) & 0xFFFF;
                matrix[matrix_num][4][row] = result[2] & 0xFFFF;
                matrix[matrix_num][5][row] = (result[2] >> 16) & 0xFFFF;
                matrix[matrix_num][6][row] = result[3] & 0xFFFF;
                matrix[matrix_num][7][row] = (result[3] >> 16) & 0xFFFF;
            }
        } else if (inst.mode == M816) {
            byte expanded8b[16];
            if (inst.sz == .U4TO8 || inst.sz == .S4TO8) {
                // Expand results from 4-bit to 8-bit
                for (int i = 0; i < 2; ++i) {   // only result[0] and result[1] are used for 4TO8
                    for (int j = 0; j < 8; ++j) {
                        size_t index = i*8 + j;
                        expanded8b[index] = (result[i] >> (4*j)) & 0xF;

                        // Sign extension
                        if (inst.sz == .S4TO8 && (expanded8b[index] & 0x8))
                            expanded8b[index] |= 0xF0;
                    }
                }
            }
            else if (inst.sz == .U4x16P64TO8) {
                for (int i = 0; i < 2; ++i) {   // result[2] and result[3] are loaded but unused (padding)
                    for (int j = 0; j < 8; ++j) {
                        size_t index = i*8 + j;
                        expanded8b[index] = (result[i] >> (4*j)) & 0xF;
                    }
                }
            }
            else if (inst.sz == .U6x16P32TO8) {
                // result[3] is loaded but unused (padding)
                uint96_t result_concat = (uint96_t)result[0] | ((uint96_t)result[1] << 32) | ((uint96_t)result[2] << 64);
                for (int index = 0; index < 16; ++index) {
                    expanded8b[index] = (result_concat >> (6*index)) & 0x3F;
                }
            }
            
            // Pack expanded results
            for (int i = 0; i < 8; ++i) {
                matrix[matrix_num][row][i] =  (expanded8b[  (i*2)] & 0xFF);
                matrix[matrix_num][row][i] |= (expanded8b[(i*2)+1] & 0xFF) << 8;
            }
        } else if (inst.mode == MT1616) {
            byte expanded8b[16];
            if (inst.sz == .8) {
                // No expansion -- just rasterize 8-bit elements
                for (int i = 0; i < 4; ++i) {
                    for (int j = 0; j < 4; ++j) {
                        size_t index = i*4 + j;
                        expanded8b[index] = (result[i] >> (8*j)) & 0xFF;
                }
            }
            else if (inst.sz == .U4x16P64TO8) {
                for (int i = 0; i < 2; ++i) {   // result[2] and result[3] are loaded but unused (padding)
                    for (int j = 0; j < 8; ++j) {
                        size_t index = i*8 + j;
                        expanded8b[index] = (result[i] >> (4*j)) & 0xF;
            }
            else if (inst.sz == .U6x16P32TO8) {
                // result[3] is loaded but unused (padding)
                uint96_t result_concat = (uint96_t)result[0] | ((uint96_t)result[1] << 32) | ((uint96_t)result[2] << 64);
                for (int index = 0; index < 16; ++index) {
                    expanded8b[index] = (result_concat >> (6*index)) & 0x3F;
            }
            
            // convert back to result array
            for (int i = 0; i < 4; i++) {
                result[i] = 0;
                for (int j = 0; j < 4; j+) {
                    result[i] = (expanded8b[(3 - i) * 4 + j] << j*8 | result[i]);
                }
            }
            
            for (int i = 0; i < 4; i++) {
                // transpose performed later
                uint32_t word32b = result[i];
                matrix[matrix_num][row][(2*i)]     = (word32b >>  0) & 0xFFFF;
                matrix[matrix_num][row][(2*i) + 1] = (word32b >> 16) & 0xFFFF;
            }
            
        } else if (inst.mode == M832) {
            byte expanded_2_to_4[32];
            for (int i = 0; i < 2; ++i) {   // only result[0] and result[1] are used for 8x32
                for (int j = 0; j < 16; ++j) {
                    size_t index = i*16 + j;
                    expanded_2_to_4[index] = (result[i] >> (2*j)) & 0x3;
                    // Sign extension
                    if (inst.sz == .S2TO4 && (expanded_2_to_4[index] & 0x2))
                        expanded_2_to_4[index] |= 0xC;
                }
            }
            // Pack expanded results
            for (int i = 0; i < 8; ++i) {
                matrix[matrix_num][row][i] =  (expanded_2_to_4[  (i*4)] & 0xF);
                matrix[matrix_num][row][i] |= (expanded_2_to_4[(i*4)+1] & 0xF) << 4;
                matrix[matrix_num][row][i] |= (expanded_2_to_4[(i*4)+2] & 0xF) << 8;
                matrix[matrix_num][row][i] |= (expanded_2_to_4[(i*4)+3] & 0xF) << 12;
            }
        }
    }
}

//
// Transpose and store results for .MT1616
//
parallel_foreach_active_thread {
    if (instr.mode == MT1616) {
        for (unsigned mtrx = 0; mtrx < (num / 2); mtrx++) {
            byte matrix8b[16][16];
            
            for (int i = 0; i < 16; i++) {
                for (int j = 0; j < 16; j++) {
                    matrix8b[i][j] = static_cast<uint8_t>((matrix[mtrx * 2 + i / 8][i % 8][j / 2] >> ((j % 2) * 8)) & 0xFF);
                }
            }
            
            // transpose the 16x16 matrix
            byte trans_matrix8b[16][16];
            for (int i = 0; i < 16; i++) {
                for (int j = 0; j < 16; j++) {
                    trans_matrix8b[i][j] = matrix8b[j][i];
                }
            }
            
            // Pack expanded results
            for (int i = 0; i < 16; i++) {
                for (int j = 0; j < 16; j+=2) {
                    matrix[mtrx * 2 + i / 8][i % 8][j / 2] =  (trans_matrix8b[i][    j] & 0xFF);
                    matrix[mtrx * 2 + i / 8][i % 8][j / 2] |= (trans_matrix8b[i][j + 1] & 0xFF) << 8;
                }
            }
        }
    }
}

//
// write data into warp wide register file
//
parallel_foreach_active_thread {
    unsigned quad = [Thread]laneId >> 2;
    unsigned quad_thread = [Thread]laneId & 0x3;

    for (unsigned matrix_num = 0; matrix_num < num; matrix_num++) {
       unsigned row = quad;
       unsigned col = quad_thread * 2;
       uint32_t Rval = (matrix[matrix_num][row][col +1] << 16) | matrix[matrix_num][row][col];
       REG_WRITE(Rval, inst.Rd + matrix_num, 32);
    }
}
